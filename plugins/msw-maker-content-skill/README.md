# MapleStory Content Skills

Optional MapleStory Worlds content-creation skills distributed separately from
the base authoring skill set.

## Included Skill

### `maplestory-skill-maker`

Advanced player attack-skill implementation patterns built around reusable
skill types, a shared registry, targeting and judgment timing, damage
presentation, knockback, casting locks, and projectile behavior.

Install it through a compatible skills client by selecting the
`maplestory-skill-maker` skill from this repository.
